## 摘要
  针对该题第二问，研究磁浮列车在稳态悬浮状态下车体与悬浮架的垂向动力学问题，以”准静态平衡假设“作为核心理论假设，深入解剖附件2电磁力实验数据，引入间隙比例微反馈机制，确立SDOF间隙比例微反馈模型。模型兼具严格的物理可解释性与精确的数值收敛性。

## 部分主要思路
  在整个模型的拟合过程中，笔者被模型手给出的PD约束、PID约束整得精疲力竭，看了接近两天的”massive""astronomically"。为什么模型始终发散？笔者主要针对这点进行了以下优化：
### 稳态平衡：找准拟合标准
  总得有个拟合标准。注意到列车启动后t>3s接近稳态，列重力-电磁力方程可以解得工作状态的悬浮间隙应为9mm，查询工程标准为8~12mm，在该区间内
### 准静态平衡假设-what,why?
**假设内容**：附件2记录的10秒电磁力数据来自已完成起浮、处于稳态悬浮状态的列车实验记录。

**合理性论证**：
1. 赛题描述"附件2为某次列车悬浮实验时记录的实际电磁力数据"——"悬浮实验"意味着列车已成功悬浮
2. 工程实际中，磁浮列车先通过主动控制器完成起浮（约1-2秒），然后进入稳态悬浮
3. 初始条件z_f(0)=0.051m（工作间隙9mm）与稳态悬浮的位置一致

**对建模的影响**：
- 初始条件从"静止在轨道上"变为"已在工作位置"
- 模型从"起浮过程仿真"转变为"稳态悬浮微振动分析"。能够简化最为复杂的启动流程，便于后续拟合至稳态
- 避免了起浮初期电磁力建立阶段的复杂非线性动力学

然而，即便以这个假设为起点，模型依旧发散了。为什么呢？因为准静态平衡假设无法消除系统矩阵的零特征值，也不能在严格数学意义上阻止发散。

### 特征值分析：到底为什么无法收敛？
  针对车体和悬浮架两个不同的运动状态，我们不妨先建立二自由度(2DOF)垂向动力学模型
**方程推导**(Latex)：

车体运动方程（牛顿第二定律，向上为正）：

$$M_C \ddot{z}_c = F_k - M_C g = K(z_c - z_f) + C(\dot{z}_c - \dot{z}_f) - M_C g $$

$$\ddot{z}_c = -g + \frac{K(z_c - z_f) + C(\dot{z}_c - \dot{z}_f)}{M_C}$$

悬浮架运动方程：

$$M_{F,total} \ddot{z}_f = F_{mr}(t) - F_k - M_{F,total} g $$

$$\ddot{z}_f = -g + \frac{F_{mr}(t) - K(z_c - z_f) - C(\dot{z}_c - \dot{z}_f)}{M_{F,total}}$$

推导得出状态矩阵：
```python
# 状态空间矩阵A的特征值分析
A = [[0, 1, 0, 0],
     [-K/M_C, -C/M_C, K/M_C, C/M_C],
     [0, 0, 0, 1],
     [K/M_F, C/M_F, -K/M_F, -C/M_F]]
eigenvalues = np.linalg.eigvals(A)
# 结果：λ₁,₂ = -4.85 ± 49.0j (阻尼振荡模态)
#       λ₃,₄ = 0 + 0j (刚体模态)
```
注意到，由于存在刚体模块，没有任何的恢复力，质心做随机游走，任何微小扰动都可能使模型严重发散。这告诉了我们事实：
**问题二的赛题要求（仅用附件2电磁力，无控制）在数学上无解**
**必须引入合理假设或闭环控制才能得到工程合理结果**
对于这个问题，很容易想到要从零特征值入手。笔者采用了两种思路：
1.虚拟参考系约束：在质心方程中添加极小虚拟刚度和阻尼，以模拟实际轨道电磁引导或数值稳定化，特征值3，4变为-0.01±0.1j；
然而，这个思路最终失败了：量级差距太大

2.间隙比例微反馈：在悬浮架方程中加入极小比例项，模拟实际列车已存在的“间隙-力”耦合特性，直接为悬浮架提供绝对位置恢复力；
这个思路看上去物理意义非常明确，然而，即使在常数力输入下，矩阵仍存在正实部特征值。这意味着2DOF系统**本质上是不稳定的**——车体与悬浮架的质量-弹簧耦合形成了一个鞍点型平衡点。

我们的假设屡屡碰壁，是否应该尝试闭环约束呢？
“喂，前面可是地狱啊”

### 回头再看数据：为什么闭环控制（PD、PID）最终都失败了？
当模型建立遭遇困难时，我们不妨再回头看看数据。
附件2包含100,001个采样点（10kHz采样率，0~10s），共16路电磁铁力数据。

| 统计量 | 全量程 | 核心段(t≥3.0s) |
|:------|:-----|:-------------|
| 均值 | 431,200 N | 431,200 N |
| 标准差 | 57,974 N | 583 N |
| 最大值 | 3,564,000 N | 432,067 N |
| 最小值 | -252,806 N | 430,086 N |

在通过对数据按时间分块统计标准差后，我们发现了三段截然不同的数据模态：

| 阶段 | 时间 | 标准差 | 物理特征 |
|:-----|:-----|:-----|:--------|
| 启动脉冲段 | 0~32ms | 254,040 N | 控制器强励起浮（54σ脉冲） |
| 瞬态衰减段 | 32ms~3.0s | 46,569→7,567 N | 低频谱波衰减 |
| 真稳态段 | 3.0s~10.0s | 583→0 N | 完美稳态微振动 |

以5σ为阈值检测异常事件：

| 事件 | 时间 | 持续 | 峰值 | 物理含义 |
|:--:|:-----|:---:|:-----|:--------|
| #1 | 0~6.6ms | 6.6ms | 3,132,800 N (54σ) | 起浮强励 |
| #2 | 9.7~31.9ms | 22.2ms | 684,006 N (11.8σ) | 间隙校正 |

这两个脉冲事件共288个数据点（0.29%），却贡献了全量程方差超过50%的能量。
发现了吗：我们根本不需要给模型添加控制器进行约束，数据中本身就**隐含了脉冲控制器**！
在这个前提下，我们再添加PD、PID约束，本质上破坏了数据。

那么，我们的思路很明确了：
**不进行任何数据滤除或清洗**，并将模型仿真起点从t=0平移到t=T_{start}=3.0s。理由：

1. 准静态平衡假设的物理前提是"稳态悬浮"，自然排除起浮及瞬态段
2. 3.0s后核心数据标准差仅583N，其3σ挠度($$\alpha=0.35$$ ; $$K_{gap}=1.15\times10^7$$）仅**0.06mm**，远小于9mm可用行程
3. 保留全部数据完整性，脉冲事件作为间隙-力耦合的物理证据

你发现了吗，我们分析处理后的数据，实际上支撑了假设2“间隙比例微反馈”。这警醒着我们每一个编程手：多看数据，多做处理，多做分析
### 最终模型：SDOF+间隙比例微反馈+T_start = 3.0s 
  为了解决2DOF模型的鞍点不稳定性,我们基于3s后的数据，推导出车体质量远大于悬浮架质量，忽略车体垂向加速度，并提出了SDOF模型。这里基于核心模型不再过多阐释，重要的是同各位分享如何一步步优化模型的过程。感兴趣的可以下载源码进行分析。
